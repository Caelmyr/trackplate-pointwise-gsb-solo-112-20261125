# TrackPlate 足印拓片测量台

从一张正拍足印拓片选前向和截面，以真实照片亮度找连续印痕，并用已知标尺得到截面宽度。适用于较浅背景与较暗印痕的图像。画面向右为 0°，顺时针增加。

1. 打开明确注明合成的练习，或导入实拍 PNG、JPEG、TIFF、BMP 或 WebP。
2. 在掌垫一带填参考原点，设前向、采样半宽、亮度上限及毫米每像素。可以直接填前后截位，也可在「取截面」模式下点照片，用该点的轴向投影定位横截。
3. 保存并测量，查看连续印痕宽度和截面的实际亮度剖面。正常读数保留原片截面的取样出处。
4. 可重开拓片卡，下载 PNG、CSV 或证据 ZIP，或将原照片直接送入照片准备。

## 新旧对照（同一毫米位置）

在当前卡片下方「新旧对照」里挑选另一张旧照拓片卡：

- 共同范围取两卡 `half_span × mm_per_px` 中较小的实际取样半宽，前后（u）与左右（v）都从各自原点向外取 ±该值，形成毫米方框。
- 同一组毫米坐标分别经两张卡自有的原点、前向角、`mm_per_px` 映回各自原片的实际像素，并用各自的 `cutoff` 做点读判定；不修改原片与标定。
- 比较格距取两卡中更清楚者的 `mm_per_px`（不细过更清楚的照片）。仅当两侧映射坐标都落在真实照片内时分为「新印 / 消失 / 都在 / 都空」，一侧缺拍记为 `outside`（缺拍）不判。
- 点格点或清单后，用现有 `/probe` 原片点读给出两张实际源坐标与亮度；共同网格的 u/v 只是毫米位置，不冒充原片坐标。
- 接口：`GET /trackplate/cards/<现在卡>/compare?other=<旧卡>`（小格网返回带多组别名字段的完整 `cells`，大格网用 `&view=compact` 取列存）、`/compare-point?other=…&u=…&v=…`、`/export/compare-proof.png?other=…` 与 `/export/compare.csv?other=…`。

`docker compose up --build -d --wait` 在本机 19915 监听。已有 Python 3.11 虚拟环境时可安装 `requirements.txt` 后执行 `./start.sh`。运行数据留在独立数据卷或普通启动的本地路径。
