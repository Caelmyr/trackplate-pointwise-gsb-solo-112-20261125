# TrackPlate 足印拓片测量台

从一张正拍足印拓片选前向和截面，以真实照片亮度找连续印痕，并用已知标尺得到截面宽度。适用于较浅背景与较暗印痕的图像。画面向右为 0°，顺时针增加。

1. 打开明确注明合成的练习，或导入实拍 PNG、JPEG、TIFF、BMP 或 WebP。
2. 在掌垫一带填参考原点，设前向、采样半宽、亮度上限及毫米每像素。可以直接填前后截位，也可在「取截面」模式下点照片，用该点的轴向投影定位横截。
3. 保存并测量，查看连续印痕宽度和截面的实际亮度剖面。正常读数保留原片截面的取样出处。
4. 可重开拓片卡，下载 PNG、CSV 或证据 ZIP，或将原照片直接送入照片准备。

`docker compose up --build -d --wait` 在本机 19915 监听。已有 Python 3.11 虚拟环境时可安装 `requirements.txt` 后执行 `./start.sh`。运行数据留在独立数据卷或普通启动的本地路径。
