# TrackPlate 足印拓片测量台

从一张正拍足印拓片选前向和截面，以真实照片亮度找掌垫的暗印痕，并用已知标尺得到实见接触面积和截面宽度。适用于较浅背景与较暗印痕的图像。画面向右为 0°，顺时针增加。

1. 打开明确注明合成的练习，或导入实拍 PNG、JPEG、TIFF、BMP 或 WebP。
2. 在掌垫一带填参考原点，设前向、采样半宽、亮度上限及毫米每像素。可以直接填前后截位，也可在「取截面」模式下点照片，用该点的轴向投影定位横截。
3. 保存并测量。只处理以原点为中心、前后和左右各一个取样半宽的原片方区：
   - 先取原点处上下左右相连的暗印痕作掌垫本体；
   - 邻块只有面对的那条实拍边能接上、且其间浅缝不超过 3 个源像素时才归入；
   - 同一道缝有多个邻块只接得分最高的一个，不跨过已接上的片继续接远处趾印。
   面积只算归入的真实暗印痕，浅缝和内部白孔留空。
4. 截面宽度沿用原截位；掌垫方式把该截线上属于掌垫的各段宽合计，空段不计，逐段列出并以 #1、#2… 标在 PNG 校样上。需要手填普通连续印痕读数时，把「读数方式」切回「普通连续印痕」。
5. 可重开拓片卡，下载 PNG、CSV 或证据 ZIP，或将原照片直接送入照片准备。

`docker compose up --build -d --wait` 在本机 19915 监听。已有 Python 3.11 虚拟环境时可安装 `requirements.txt` 后执行 `./start.sh`。运行数据留在独立数据卷或普通启动的本地路径。
